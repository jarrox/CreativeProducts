# Tender Control Releases

Official distributable releases for Tender Control by Creative Products Limited.

[Download the latest Tender Control release](https://github.com/jarrox/CreativeProducts/releases/latest)

## Release policy

Every completed and verified Tender Control update is published here as a versioned GitHub Release. Releases may contain installers, application bundles, SHA-256 checksums, release notes, and documentation approved for public distribution.

This public repository must never contain customer-specific deployment packages, credentials, `.env` files, API keys, QuickBooks tokens, customer data, backups, licence files, the private licence-signing key, or source code unless Creative Products Limited explicitly approves making that source public.

Always verify downloaded release assets with their matching SHA-256 checksum before installation.
